# Global Architecture Constraints

> These constraints apply to ALL phases of the Infusion AI Screener architecture.

| # | Constraint | Bias |
|---|---|---|
| 1 | No over-engineering | Simplicity-first, single-machine, evolutionary scaling |
| 2 | Latency priority | Tick-to-signal speed, low CPU/memory, incremental compute, cache locality |
| 3 | Signal quality > quantity | High conviction, institutional-grade filtering, low noise |
| 4 | Sector intelligence is core | Breadth, momentum, rotation, relative strength, money flow, confirmation |
| 5 | Pre-breakout detection is core edge | Compression, accumulation, vol contraction, liquidity absorption, smart money |
| 6 | Dashboard UX: focus & clarity | Low cognitive load, rapid identification, minimal clutter, infographic readability |
| 7 | Resource awareness | Market hours = high-perf, post-market = analytical, overnight = low-power |
| 8 | Configurability | YAML thresholds, dynamic enable/disable, runtime reload, no redeployment |
| 9 | Feature prioritization | Scanner quality + sector intel + realtime + UX over fancy ML + excessive indicators |
| 10 | Implementation-grade depth | Practical detail, not generic concepts |
